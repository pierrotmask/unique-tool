プライバシーポリシー

Unique Tool ／ 制定日：2026年11月22日

1. 対象

このポリシーは、https://pierrotmask.github.io/unique-tool/ で公開しているウェブアプリ（LiftCanvas など。以下「本アプリ」）に適用されます。

2. 保存するデータと保存場所

  • 本アプリで入力した記録や設定は、お使いの端末のブラウザ内（localStorage など）にだけ保存されます。
  • 本アプリには運営者のサーバーやデータベースがなく、入力内容が運営者に送信されることはありません。
  • アクセス解析・広告・トラッキングのためのツールは使用していません。

3. Googleドライブへの保存（任意）

一部のアプリでは、利用者が自分で操作した場合に限り、バックアップを利用者ご本人のGoogleドライブに保存・復元できます。

  • 使用する権限は https://www.googleapis.com/auth/drive.file のみです。これは本アプリが作成したファイル、または利用者が本アプリで開くことを選んだファイルだけを扱える権限で、ドライブ内のほかのファイルを閲覧・変更することはできません。
  • ファイルの読み書きは、利用者の端末から Google の API に直接行われます。運営者がファイルの内容やGoogleアカウントの情報を受け取ったり、保存したりすることはありません。
  • Googleから受け取ったアクセス権（トークン）は、保存・復元の処理のためにその端末内でのみ一時的に使用します。
  • Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。取得した情報を第三者に提供したり、広告や本アプリの機能以外の目的に使ったりすることはありません。
  • 連携は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも解除できます。

4. 外部サービスの読み込み

表示やグラフのために、フォントやライブラリを外部の配信サービス（Google Fonts、jsDelivr、cdnjs など）から読み込む場合があります。その際、各サービスに IP アドレスなどの一般的な接続情報が送られることがありますが、本アプリの入力内容は送られません。

5. データの削除

  • 端末内のデータは、各アプリの設定にある「すべてのデータを削除」や、ブラウザのサイトデータ削除で消去できます。
  • Googleドライブに保存したバックアップは、利用者ご本人がGoogleドライブから削除できます。

6. 改定とお問い合わせ

このポリシーを改定する場合は、このページで告知します。お問い合わせは、Googleの同意画面に表示されるサポートメール、または GitHub リポジトリまでお寄せください。
